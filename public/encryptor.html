Encrypt a question file

Turn your .tsv question file into a password-protected .lock file, so students can't read the answers before they play. Give students the .lock file and the class password; the game asks for the password when they open it.

  • The encryption happens in this browser: your file is never uploaded.
  • Passwords are case-sensitive. Keep your original .tsv: a .lock file can't be opened without its password.
  • Load the plain .tsv in the game first, to check it, before you encrypt it.
  • This keeps casual eyes off the answer key. It isn't strong security, since every student knows the password.

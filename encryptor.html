Question Encryptor

Lock your question file with a class password, so students can't read the answer key by opening the file.

  • Load the plain .tsv in the game first to check it, then encrypt it.
  • Passwords are case-sensitive. Keep your original .tsv: a .lock file can't be opened without its password.
  • Give students the .lock file and the password; the game asks for the password when they open it.
How secure is this?
  • The file is encrypted in this browser with AES-256-GCM, using a key derived from the password (PBKDF2-SHA256, 600,000 rounds). Nothing is uploaded.
  • It keeps the answers out of sight of anyone who opens or shares the file without the password.
  • It is not a way to keep answers secret from your class: every student who has the password can unlock the file, and the game shows each answer after it is played.
  • A weak password can be guessed by someone determined. Use a phrase, not a single word.
